# Audio Frequency Analyzer
This script decomposes MP3 files into frequency components using FFT.

## Requirements
- `pydub` (for audio conversion)
- `numpy`, `matplotlib`, `scipy` (for signal processing and visualization)

## Usage
1. Place your MP3 file in the working directory
2. Run the script: `python fft-audio-analyzer.py`
3. Enter the file path when prompted
4. View the frequency spectrum plot
